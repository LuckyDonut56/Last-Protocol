# Last Protocol

## Идея

**Last Protocol** — сюжетная 3D-головоломка от первого лица с элементами психологического хоррора. Игрок оказывается на борту повреждённого ковчега, направлявшегося к Венере, и общается лишь с голосом ИИ-помощника. Земля погибает из-за остывающего Солнца, а на целевой планете обнаружена опасная форма жизни. От действий обычного человека зависит выживание человечества.

Игра — для любителей атмосферных научно-фантастических головоломок и психологического хоррора, ценящих сюжет, исследование и напряжение.

## Тип проекта

3D-игра (головоломка от первого лица с элементами психологического хоррора).

## Цель и задачи

**Цель:** создать атмосферную сюжетную головоломку, погружающую игрока в изолированное и опасное космическое путешествие, где решение логических задач определяет судьбу колонистов.

**Задачи:**
- Реализовать управление, взаимодействие с окружением и разнообразные головоломки.
- Создать различные комнаты (отсеки) корабля.
- Добавить сюжет, развивающийся через взаимодействие с окружением.
- Проработать звуки окружения (сирены, гул корабля, голос ИИ).

## Структурные части и технологии

- **Игровой движок — Unity (C#):** реализация 3D-сцены, управления от первого лица, взаимодействия с объектами и логики головоломок.
- **Сюжет и диалоги — внутриигровые скрипты и триггеры:** ветвление повествования через взаимодействие с окружением и реплики ИИ-помощника.
- **Уровни (отсеки корабля) — 3D-сцены Unity:** комнаты с собственными головоломками и атмосферой.
- **Звук — аудиосистема Unity (AudioSource / AudioMixer):** фоновый эмбиент, сирены, звуки окружения и озвучка ИИ.
- **Интерфейс — Unity UI:** подсказки, взаимодействие, элементы повествования.

## Запуск и проверка

1. Перейти на страницу проекта на GitHub и открыть раздел **Releases**.
2. Скачать архив с последней версией игры (`.zip`) из релиза.
3. Распаковать архив в удобную папку.
4. Запустить исполняемый файл игры (`.exe`) из распакованной папки.
5. Играть, управляя персонажем: `WASD` (перемещение), мышь (обзор), `E` (взаимодействие с объектами).

> Для запуска из исходников: установить **Unity Hub** и версию редактора Unity, указанную в `ProjectSettings/ProjectVersion.txt`, открыть папку проекта через Unity Hub (**Add project from disk**), дождаться импорта ассетов, открыть сцену запуска и нажать **Play**.

## Подсказки для жюри

**Тестовые сценарии:**
1. **Старт:** запустить игру — проверить, что сцена загружается, слышны звуки и работает управление.
2. **Исследование:** пройти по отсекам корабля, проверить взаимодействие с объектами.
3. **Головоломка:** решить первые логические задачи во взаимодействии с окружением и убедиться, что сюжет продвигается.
